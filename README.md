# 📡 Request Header Parser Microservice

This project is part of the **APIs and Microservices Certification** from [freeCodeCamp](https://www.freecodecamp.org/learn/apis-and-microservices/apis-and-microservices-projects/request-header-parser-microservice).

It is built using the provided boilerplate to create a simple API endpoint that parses and returns information from request headers.

### 🚀 Features
- Returns the IP address, language, and software (user-agent) of the client
- Demonstrates handling HTTP headers in a Node.js/Express app
